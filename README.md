# HR BP Tinder

HR BP Tinder is a playful HR tool for quickly reviewing employee profiles with a Tinder-like swipe interface.
Available on: https://nickhero.github.io/hrbptinder/

## Features

- Swipe left, right, up, or down to make HR decisions (promote, fire, warn, or put back)
- Keyboard and mouse support for fast navigation
- Instant feedback and match notifications
- Add new employees and view history

## Usage

Open the app, log in with your name and employee number, and start swiping through the cards. Use the action buttons or arrow keys to make decisions. Your choices are tracked and displayed in the app.
